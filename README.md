# demo-terapie-corporala

Demo WordPress Playground of the "Terapie Corporală" theme v4 (same structure as the live site, new design).

Open: https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/maximus323/demo-terapie-corporala/main/blueprint.json

- `blueprint.json` — imports the pages, installs the demo images plugin and the theme, sets the front page and sidebar widgets.
- `tc-demo-imagini.zip` — demo only: shows the photos hosted on terapiecorporala.ro. Never install it on the real site.
